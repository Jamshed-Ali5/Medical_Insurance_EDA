# Medical Insurance Cost – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) and data preprocessing using a Medical Insurance dataset.

The objective is to understand the dataset, explore numerical and categorical variables, identify data quality issues, visualize distributions, examine correlations, and prepare features for further data analysis and machine learning applications.

## Dataset Information
- Dataset: Medical Insurance (`insurance.csv`)
- Original records: 1,338
- Features: 7
- Target-related variable: `charges`

### Dataset Features
| Feature | Description |
|---|---|
| age | Age of the individual |
| sex | Gender |
| bmi | Body Mass Index |
| children | Number of children |
| smoker | Smoking status |
| region | Residential region |
| charges | Medical insurance charges |

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

### 1. Exploratory Data Analysis
- Dataset inspection
- Data dimensions and data types
- Statistical summaries
- Missing-value analysis
- Duplicate detection
- Column identification

### 2. Data Visualization
- Histograms for numerical variables
- Count plots for categorical variables
- Boxplots for outlier exploration
- Correlation heatmap

### 3. Data Cleaning and Preprocessing
- Duplicate removal
- Binary encoding of categorical variables
- One-hot encoding of region
- Data type handling

### 4. Feature Engineering
- BMI categorization into:
  - Underweight
  - Normal
  - Overweight
  - Obese
